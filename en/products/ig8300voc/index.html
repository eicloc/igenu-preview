IG8300VOC Online Odor and Gas Monitoring System

Monitor configured odor-related gases through a multisensor system with sample pretreatment, temperature compensation and automatic calibration functions. An integrated display, data storage and communication options support connected environmental monitoring at wastewater treatment, chemical production and waste-handling sites.

Overview

Product features:
★ Adopting high-precision electrochemical sensors, with reliable and stable performance
Equipped with independent algorithms to ensure accurate and reliable data
★ Built in multiple pre-treatment systems such as dust removal, water removal, and heat dissipation, effectively extending the service life
★ Integrated temperature compensation technology+automatic calibration technology, intelligent calibration without manual intervention
★ Integrated GPRS communication technology, real-time monitoring data can be connected to the environmental protection bureau platform
★ Adopting a 7-inch industrial touch screen display and a larger screen for clearer display
★ Built in 16GB memory card, data can be stored for 2-5 years
★ Equipped with a 32-bit high-speed processing chip and automatic networking function for power-off and power on monitoring
★The sensor has automatic cleaning and intelligent calibration functions, with 365 * 24-hour continuous monitoring without any pressure
★ Special appearance design, anti-interference

Technical Parameter
Gas detection: NH3、C9H9N、H2S、CH4S、C2SH6、C2H6S2、CS 2、C8H8、OU、VOC、T、H、PM2.5、PM10 
Measurement range: Odor: 0-2000 NH3 C9H9N、H2S、CH4S、C2SH6、C2H6S2、CS 2、C8H8：0-100ppm,  Volatile gases (VOCs): 0-100ppm PM2.5, PM10: 0-1000ppb
Resolution: 1OU; 0.01ppm,1ppb 
Response time: T90≤20s 
Measurement accuracy: ± 3%
Linear error: ≤ ±1% 
Zero drift: ≤ ± 1% (F.S/year)
Recovery time: ≤ 20 seconds
Installation methods: column clamp type, wall mounted type
Repeatability: ≤ ±1% 
Protection level: IP65 
Temperature and humidity: optional accessories, temperature detection range: -40~800 ℃, humidity detection range: 0-100% RH
Alarm settings: The alarm value can be set arbitrarily
Data storage: Standard configuration includes storage of over 100000 pieces of data, supports large capacity SD cards, continuous data storage for more than one year, and allows for free setting of data storage intervals
Signal output: Supports wireless or wired transmission methods such as RS485, GPRS, 433M, NBIOT, LoRa, etc
Working environment: Working temperature -30~50 ℃ (customized or optional pre-treatment system required for use in higher temperature and humidity environments) Working humidity: ≤ 95% RH, no condensation
working pressure: 0 ～ 100Kpa 
Working power supply: 220VAC
