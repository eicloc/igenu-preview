IG9600 Ultrasonic Sludge Interface Monitor

Ultrasonic echo timing identifies the sludge interface in settling and thickening tanks. A separate probe, integrated temperature compensation and local display support monitoring in wastewater treatment and waterworks sedimentation processes, with configuration adapted to the installation.

Overview

Product features:
◆ Split type, suitable for different on-site installation requirements
◆The host has a Chinese and English operating interface, which can achieve functions such as multi-point measurement and alarm
◆ Simple to use, reliable results, interface operation instructions can reduce operational errors
◆The probe material is available in POM, PVDF, PTFE options, suitable for various working conditions

◆ Internally integrated temperature sensor, capable of real-time temperature compensation for sound velocity

Technical parameters:

Measurement range: 0.2~10/15/20m
Resolution:< 0.04m 
Accuracy: 0.1m ± 0.05m
Response time: 10-900s (adjustable)
Calibration: It only needs to be performed once when turning on the device
Automatic pressure range: ≤ 0.3bar 
Environmental temperature: 0-50 ℃
Temperature compensation: automatic compensation
Protection level: IP68 
Flow rate requirement: ≤ 3m/s
Size: 140mm × 195mm (H × D)
Weight: Approximately 3.5Kg
Maintenance: Regular<1 hour/month
Cable length: 10m, extended by at least 100m
Output: 2-channel 0/4-20mA, load 750 Ω
Alarm: Multi way relay, 220VAC/2A 485
Signal: Modbus protocol (optional)
Process temperature: transmitter: -30 ℃~80 ℃; Sensor:- 40℃~80℃ 
Protection level: Transmitter: IP65； Transmitter: IP68 
Power Supply: DC18-36V； AC90-260V
